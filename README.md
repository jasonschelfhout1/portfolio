# Portfolio

Minimal personal portfolio built with React, TypeScript, Vite, Tailwind CSS,
and the official shadcn/ui Card component.

## Development

Use Node.js 22.12+ and npm.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run lint
npm run preview
```

The production build is written to `dist/`.

## Project links

Edit `src/projects.ts` to update the DataScraper URLs. The website URL is a
planned deployment address; this portfolio does not confirm that it is live.
